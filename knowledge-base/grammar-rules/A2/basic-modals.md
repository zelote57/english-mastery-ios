# A2_ADV: Basic modals

Use **can + base verb** for ability or permission: “She can swim.” **Could + base verb** can express past ability or a polite request: “Could you help me?” Use **have to + base verb** for an obligation: “I have to leave.” With he/she/it in the present simple, use **has to**; for ordinary negatives and questions use **do/does**: “Does he have to go?”

After **can** and **could**, do not add **to** or a third-person **-s**. **Cannot/can't** expresses inability or prohibition depending on context. **Don't have to** means there is no obligation; it does not mean the same as **mustn't**, which expresses prohibition.

- ❌ “He can swims.” → ✅ “He can swim.” — Él sabe nadar.
- ❌ “Could you to help me?” → ✅ “Could you help me?” — ¿Podrías ayudarme?
- ❌ “She have to work.” → ✅ “She has to work.” — Ella tiene que trabajar.
- ❌ “You don't have to enter: it is forbidden.” → ✅ “You mustn't enter: it is forbidden.” — No debes entrar: está prohibido.

Spanish often uses an infinitive after these meanings; English modal verbs require the base form without **to**.
