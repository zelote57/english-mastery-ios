# 🇪🇸 Spanish Interference — Knowledge Base

Common mistakes made by Spanish speakers when learning English.

## Categories

### False Friends
Words that look similar in Spanish and English but have different meanings:
- **actually** ≠ actualmente (= currently)
- **realize** ≠ realizar (= to carry out)
- **sensible** ≠ sensible (= sensitive)
- **embarrassed** ≠ embarazada (= pregnant)

### Problematic Prepositions
- "Depende **de**" → "It depends **on**" (not "depends of")
- "Soñar **con**" → "Dream **about/of**" (not "dream with")
- "Casarse **con**" → "Marry ∅" / "Get married **to**" (not "marry with")

### Structural Errors
- Double negation: "I don't have nothing" → "I don't have anything"
- Adjective order: "a car red" → "a red car"
- Subject omission: "Is raining" → "It is raining"

## Document Format
- One `.md` file per error category
- Include: common mistake, explanation, correct rule, 3+ examples
